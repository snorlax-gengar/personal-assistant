# 🤖 PersonalAssistant (실시간 자동 수집 & 아이폰 16 프로 연동 올인원 개인 비서)

macOS 메뉴바와 바탕화면에 상주하며 **미국 M7/반도체 주식 실적 발표(Earnings)** 및 **수도권 주요 청약 일정(일반분양, 신희타, 공공분양, 줍줍)**을 자동으로 수집하여, **아이폰 16 프로의 카테고리별 Apple 캘린더 및 위젯**과 100% 전자동으로 동기화해 주는 올인원 개인 비서 앱입니다.

---

## ✨ 핵심 기능 완벽 정리

### 1. ⌨️ 어디서든 1초 만에 여는 전역 단축키 (`Option + Space`)
* 다른 앱(크롬, 슬랙, 문서 등) 작업 중 언제든 **`⌥ (Option) + Space`**를 누르면 대시보드가 화면에 즉시 팝업됩니다.
* 마우스 없이 키보드만으로 할 일을 빠르게 확인하고 등록할 수 있습니다.

### 2. 🎞️ 고정 너비 롤링 전광판 (메뉴바 흔들림 방지)
* 상단 메뉴바의 가로 사이즈가 **155pt로 완전히 고정**되어, 주변의 Wi-Fi, 배터리, 시계 아이콘들이 좌우로 전혀 덜컹거리지 않습니다.
* 3.5초마다 다가오는 주요 일정(`🏠 과천 디에트르 D-2`, `📈 삼성전자 실발 D-5` 등)이 아래에서 위로 부드럽게 자동 전환됩니다.

### 3. 🔗 주식(장전/장후 & 차트 링크) + 🏠 청약(분양 상세 링크)
* **주식 실발 디테일**: `장 마감 후 (AMC)` 또는 `장 시작 전 (BMO)` 시간대가 태그로 표시됩니다.
* **원클릭 웹 상세 링크 (`↗`)**: 각 항목 우측 링크 버튼을 누르면 Yahoo Finance, 네이버 증권, 네이버 부동산/청약홈 페이지로 브라우저에서 즉시 열립니다.

### 4. 🚀 Mac 부팅 시 자동 실행 (Launch at Login)
* 대시보드 상단에서 `부팅 시 자동실행 [ON]` 스위치를 켜두시면 맥북 재부팅 후에도 메뉴바에 조용히 상주합니다.

### 5. ☀️ 출근 시간 모닝 브리핑 시스템 알림 (오전 09:00)
* 매일 아침 9:00 맥북 우측 상단에 오늘 놓치면 안 되는 D-Day와 할 일을 요약한 시스템 배너 알림을 띄워줍니다.
* 대시보드 하단 `[알림 테스트]` 버튼으로 즉시 테스트해볼 수 있습니다.

### 6. 📱 아이폰 16 프로 4개 카테고리 독립 동기화
* Apple 캘린더에 카테고리별 독립 캘린더가 자동 생성됩니다:
  * 📈 **`[비서] 주식·실적`** (초록색)
  * 🏠 **`[비서] 부동산·청약`** (주황색)
  * 💼 **`[비서] 개인·업무`** (파란색)
  * ✅ **`[비서] 할 일`** (보라색)
* **전날 오전 9시 + 당일 오전 9시 스마트 푸시 알람**이 자동 설정됩니다.
* 사용자가 직접 입력한 개인 일정은 100% 안전하게 보존됩니다.
